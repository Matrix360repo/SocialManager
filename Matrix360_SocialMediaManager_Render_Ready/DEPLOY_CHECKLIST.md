- [ ] Repository private; no `.env` or `OPENAI_API_KEY` tracked
- [ ] `app.py`, `render.yaml`, `Dockerfile`, `requirements.txt` at root
- [ ] Render `starter` plan and persistent disk monthly cost approved
- [ ] `MATRIX360_API_KEY` securely configured, 32+ chars
- [ ] `OPENAI_API_KEY` stored only as Render environment secret
- [ ] `/health` returns JSON 200 without key
- [ ] `/api/drafts` returns 401 without key, 200 with proper auth
- [ ] Generate drafts with real AI provider (not offline_template)
- [ ] Render all three previews without missing fonts/assets
- [ ] AI revision creates new version; compliance checked
- [ ] Unapproved version export rejected; approved version ZIP succeeds
- [ ] Restart server; verify draft and approved images persisted
- [ ] No automatic publishing or paid campaign actions enabled
